# banner

Redirecionamento do QR code do banner.

**Endereço fixo do QR code:** https://sstertz.github.io/banner/

## Como trocar o vídeo
1. Abra https://github.com/sStertz/banner/edit/main/index.html
2. Na linha `var DESTINO = "";` coloque o link do vídeo entre as aspas.
3. Clique em **Commit changes**. Em ~1 minuto o QR já leva para o novo link.
